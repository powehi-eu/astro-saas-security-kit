# Astro SaaS Security Kit v0.1.0

Pack de prompts, checklists et modèles défensifs pour auditer et renforcer une application SaaS construite avec Astro.

## Utilisation

1. Commencez par `QUICKSTART.md`.
2. Remplacez les variables indiquées entre chevrons (`<CONTEXTE>`).
3. Ne transmettez jamais de secret réel à un modèle d'IA.
4. Faites relire et tester chaque proposition avant mise en production.

Ce kit n'est ni un audit certifié ni un avis juridique. Les exemples privilégient la sécurité, mais doivent être adaptés à votre architecture.
